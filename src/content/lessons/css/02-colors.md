## Set a text color

CSS accepts named colors such as `tomato`, as well as color values like hex codes. Pick colors that keep the text easy to read against its background.

This plain code fence is shown as a normal code sample:

```css
.notice {
  color: #193322;
  background-color: #e4f3e9;
}
```

## Add a background

A live CSS fence includes a small preview. Edit the rules and watch the page update:

```css live
body {
  background-color: #eff9f1;
  color: #193322;
}

h1 {
  color: #277a49;
}

button {
  background-color: #277a49;
  color: white;
  border: 0;
  padding: 0.6rem 1rem;
  border-radius: 0.4rem;
}
```

Try changing the page background or the heading color.

## Try it yourself

Pick a background and text color that are easy to read together. Try changing the button color too.
